# 🍺 めっちゃマーライオン

酔いは、遅れてやってくる。

居酒屋でマーライオンが飲むドット絵のブラウザゲームです。お酒の効き目は飲んだ瞬間ではなく遅れて回ってくるので、「まだ平気」と思って飲み続けると、やめた後でもマーライオン(吐く)になってしまいます。実際の飲み会での飲み方を記録して、練習に生かすこともできます。

## 遊び方

- PC: `index.html` をブラウザで開く。
- スマホ: GitHub Pages などで公開した URL を開き、ホーム画面に追加する(オフラインでも開けます)。

ビルドやインストールは不要です(HTML・CSS・JavaScript のみ)。

## モード

| モード | 内容 |
| --- | --- |
| スコアアタック | 2時間の飲み会を120秒で。注文表から頼み、器を長押しして飲む。安全にたくさん飲んでハイスコアを狙う |
| 練習モード | 自分の飲み方のくせをレポートで振り返る。記録モードの記録が5回以上あると、あなた専用の数値で遊べる |
| 記録モード | 実際の飲み会で、自分が飲んでいる間だけ器を長押しして記録する。過去と比べたペースの提案が出る |

## ファイル構成

```
index.html        画面(すべての画面を1ページに持つ)
manifest.json     ホーム画面に追加するための設定
sw.js             オフライン対応(サービスワーカー)
css/style.css     見た目
js/               プログラム(index.html に書いた順番で読み込む)
  config.js         定数、お品書き、練習モードの数値
  storage.js        ユーザー・履歴・ハイスコアの保存
  state.js          1プレイごとの状態、画面の切り替え
  game.js           ゲームの進行
  results.js        標準モデルとの比較、結果画面の文章とグラフ
  render-scene.js   居酒屋の店内、飲み仲間、タイトル画面
  render-merlion.js マーライオンと器の描画
  render-game.js    ゲーム画面と結果画面の絵
  record.js         記録モード
  app.js            レイアウト、メインループ、イベント
assets/           アイコン
```

## データの保存

記録はすべて、使っているブラウザの中(localStorage)にだけ保存されます。サーバーには送りません。ブラウザの閲覧データを消すと、記録も消えます。

## ご注意

ゲーム内の酔いの推定や提案は、簡易なモデルによる目安であり、医学的な診断ではありません。20歳未満の飲酒、飲酒運転は法律で禁止されています。
